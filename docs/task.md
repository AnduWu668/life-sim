# 需求：角色生活模拟

导入 AI 聊天角色卡（酒馆卡或自定义角色描述卡），生成符合该角色的连续故事：以文字演绎角色经历的不同生活、碰到的不同的人。通过「故事走向」功能调整角色接下来的生活故事。

要求：

1. 故事有连续性和相关性，一段一段进行，像角色的生活章节或片段；能无限延续，至少输出 100 段以上。
2. 内容符合角色基础设定，走向可按「故事走向」控制，故事自洽即可。
3. 故事走向要起作用，影响接下来故事的整体感觉。
4. 读起来有吸引力：小说、日记或社交媒体方式均可；让观看者感到悲伤、开心、治愈等情绪。
5. 至少测试 3–5 个角色，验证对不同角色输出的有效性。
6. 载体不限（web / app），以能交互演示为目标；技术不限，以能运行为目标。
